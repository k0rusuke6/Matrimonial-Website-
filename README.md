# Matrimonial-Website-
A modern Matrimonial Website developed using HTML, CSS, JavaScript, PHP, and MySQL. The main purpose of this project is to help users find suitable life partners through an online platform. Users can create their profiles by entering personal details such as name, age, gender, religion, education, occupation, hobbies, and preferences.
The website provides a multi-step registration system, login authentication, profile management, and a dashboard where users can view recommended matches. Users can search and filter profiles according to their preferences like age, city, religion, and profession.
The project also includes interactive features such as Like and Message options, allowing users to connect and communicate with interested matches. A chat system is implemented where clicking the message button opens a direct conversation between two users.
The backend is developed using PHP and MySQL for storing and managing user data securely, while the frontend is designed using HTML, CSS, and JavaScript for a responsive and user-friendly interface.
Overall, this project demonstrates the practical implementation of web development, database management, user authentication, session handling, and dynamic content integration in a real-world matrimonial platform.

Technologies Used

Since this is a PHP and MySQL-based project, it requires a local server environment such as XAMPP to run successfully.

Steps to Run the Project
Install XAMPP on your computer.
Copy the project folder into the htdocs directory inside the XAMPP folder.
Start Apache and MySQL from the XAMPP Control Panel.
Open phpMyAdmin and import the database file provided inside the database folder.
Open your browser and run the project using:
http://localhost/Website

The website will then open on the localhost server.
